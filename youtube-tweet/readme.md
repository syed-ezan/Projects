Introduction:

YouTube-Tweet is a pure backend application which supports functionalities of YouTube and Twitter. From uploading videos and tweets to liking and commenting on them, all those features are deployed in this application. You can also watch them, which automatically updates your watch history. So, it is a basic project which contains advanced concepts as well.

How it works:

First, you must register your email; attempting to register with an already existing email will result in an error. Once your verification passes, you can successfully log into the application. Since this is a backend system, selecting a video returns its respective document, allowing you to watch, comment on, and like videos. As you interact with the platform, your watch history and liked videos are automatically updated, and video views are generated uniquely. Furthermore, you can subscribe to other channels and upload media files to the server, which handles storage via Cloudinary and saves the records in the database.
Ultimately, this project is a robust backend system for a video-sharing and social media platform that seamlessly handles user authentication, media uploads, and dynamic user interactions like history tracking, comments, and subscriptions.

Keys to run server and send request:

npm run dev to start the server \n
use postman to send the request
